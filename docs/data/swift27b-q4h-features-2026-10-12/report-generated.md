# Swift 27B：Q4H 基准的 ANE、lookup 和 compact 对照

固定同一份混合量化 GGUF 和匹配的 DFlash2。输入为 32,768 tokens，实际输出为 16,384 tokens，上下文容量为 131,072，并发为 1。DFlash2 block=8，尾段 splits=16，关闭 fast top-k 和自动 ANE 校准。

| --- | --- | --- | --- |
| A：保留基准 | 开，share=0.5／阈值 512 行 | 开 | 开 |
| B | 关 | 开 | 开 |
| C | 开，share=0.5／阈值 512 行 | 开 | 关 |
| D | 开，share=0.5／阈值 512 行 | 关 | 开 |
| E | 开，share=0.5／阈值 512 行 | 关 | 关 |

先验证正确性，再按 ABCDE、EDCBA、CDEAB 顺序测量，每组 3 次。模型加载、ANE 准备及相同预热均不计入请求时间。检测到后台活动时取消当前样本并保留证据，等待空闲后重试。

ANE 的 W8A8 路径会改变主模型预填充数值。首次跨 ANE 对照在第 40 个 token 分歧，原始失败保留。校验维持 ANE 贡献 RMS 误差不超过 10%、同路径分数相对误差不超过 1e-3、分块状态 cosine 大于 0.999。各路径分别检查冷重复 token 一致性，跨路径记录首次分歧。启动 FFN 数值验证覆盖前两层和所有编译的 ANE 行数，不能替代完整输出的质量检查。

正确性 7 项和性能 15 次均完成，控制器真实退出码为 0。A、C、D、E 的完整输出与原 Q4H 基准逐 token 相同；B 的完整输出在自身路径冷重复时逐 token 相同。

按总耗时中位数，候选配置为 A。当前基准仍保留 A；候选需要与 A 做 ABBA 确认，再研究 ANE share 和 splits。
