# 领域文档

本仓库采用单上下文，领域术语和架构决定分别保存在根目录 `GLOSSARY.md` 与 `docs/adr/`。

## 探索顺序

1. 工程任务探索前读取术语表。
2. 阅读涉及变更区域的 ADR，按其约定分析和实施。
3. 若以后存在 `GLOSSARY-MAP.md`，先按地图确定相关上下文，再读取对应文档。

文件不存在时继续任务，按实际需要通过领域建模流程补充。

## 使用规则

- 规格、issue、测试名称和设计讨论采用术语表中的词汇。
- 术语表只定义领域概念，规格和实现决策分别记录。
- 方案与既有 ADR 冲突时明确指出冲突及取舍，取得决定后再更新记录。
- 新增 ADR 应来自真实取舍，并具有长期影响及需要保留的背景。
