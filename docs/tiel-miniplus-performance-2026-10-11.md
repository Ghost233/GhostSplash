# Tiel MiniPlus 完整性能测试记录

## 结果和建议

本轮完成 236 次测量：逐项扫描 156 次、交叉组合 48 次、最终 ABAB 32 次。另完成 10 次初始正确性运行。所有 246 次原生运行退出码为 0。

230 个样本通过性能与事实校验。其余 6 个样本是 ANE 请求开启后回退 GPU 的诊断，按 unsupported 保存。没有失败、跳过、丢弃慢样本或因波动重跑。

短长输出共用参数时，建议从 INT8、splits=8、DFlash2 block=8、并发 1、lookup 和 compact 关闭开始。长输出可单独开启 lookup。参数建议不自动修改生产服务。

| 参数 | 建议值 | 依据 |
| --- | --- | --- |
| 主模型 | Tiel-Coder-35B-A3B.APEX-I-MiniPlus-V2.1.gguf | 本轮使用原始文件 |
| KV | INT8 | 交叉组合中短长输出综合总耗时最优 |
| 历史 splits | 8 | 原版基准；splits=3 的扫描优势未在交叉组合中保持 |
| Drafter | DFlash2 开启，block=8 | 当前模型契约只支持这一执行形态，1 个 anchor 和 7 个草稿 token |
| ANE | 关闭，GPU 执行 | MoE 没有注册可供 ANE 执行的稠密 FFN 层 |
| 并发 | 1 | 单请求延迟基准；并发结果另列 |
| Prompt lookup | 共用基准关闭；长输出可开启 | 短输出 decode 配对下降 5.26%，长输出提升 6.37% |
| Compact draft head | 关闭 | 扫描没有证明共同收益，额外分配 159.375 MiB |
| Fast top-k | 关闭 | 固定 greedy 请求不执行该采样路径 |

## 最终 ABAB 复核

A 为原版 INT8／splits=8 基准，lookup 关闭；B 只开启 lookup。其他参数完全相同。

每种输出 8 对相邻 AB，执行顺序为 A512、B512、A2048、B2048，重复 8 次。共 32 个样本，执行约 19.4 分钟。
模型加载和预热不计入请求耗时。首 token 和总耗时包含请求的调度等待。表中为各组中位数。

收益先按相邻配对计算，再取中位数。各组中位数的比值与配对收益是两种统计量。

A、B 在同一输出长度下逐 token 一致。512 输出中，lookup 接受 191 个复制草稿 token；2,048 输出接受 1,497 个。短输出的 lookup 开销没有换来 decode 收益，长输出有稳定的配对 decode 提升。

Lookup 不改变 prefill 计算。本轮相邻配对的 prefill 差异应视为时间与负载波动，不能归因为 lookup 加速。固定 AB 顺序仍可能包含顺序偏差。

## 范围和校验限制

KV 扫描为 INT8、BF16、Q4_0、Q4_0 unrotated 和 Q4H。主模型 GGUF 权重量化始终固定，未测试不同主模型权重量化文件。历史 splits 覆盖 1～16 的所有整数；并发覆盖 1、2、4；输出固定为实际 512 和 2,048 tokens。

初始正确性包括两次短输入重复和 8 次 32K 特性检查，使用 INT8／splits=1。性能阶段 INT8／splits=8 的特性开关也逐 token 对照基准。交叉与最终配对均检查同 KV／splits 下的开关一致性、输出长度、事实、内存和真实退出码。

不同 KV／splits 允许记录输出轨迹差异，完整原始输出和首次分歧均保留。事实检查不能替代数值校验。本次没有改生产算子；原源码的数值与仓库门禁结果复用 build/ghost-merge-validation 和 build/accuracy-5ea170c-v1。新 MoE 模型的证据范围为本轮端到端验证。

当前实现不支持该 MoE 模型的 drafter 关闭、DFlash2 block 2／4／16、真实 ANE 开启和 4B 专用 FFN 缓存实验。因此这些设置没有伪装为已测试。ANE 的 6 次请求开启诊断，实际执行次数均为 0。

所有性能记录均未检测到其他活动推理，但服务检测不是全 GPU 工作的穷尽检查。按用户授权接受桌面和后台波动，不将结果标为隔离环境的稳定上限。原始 GPU 采样保留。

并发 2／4 同时提交独立冷请求。实际 decode 批宽常为 1，完整分布在原始数据中。请求速度和批吞吐分列，不能把并发数量直接当作算子批宽。EngineConfig.decodeShare 固定为原版 0.5，它与 ANE share 不同。

### 原始记录与限制

原 GGUF 权重固定，5 种 KV 格式不是 5 个主模型量化版本。
所有速度波动保留；配置三轮分别正序、反序、轮换，长短输出顺序交替。后台负载按授权接受，不停止其他服务。
Lookup／compact 排名只依据固定输入，未使用预期输出；强制长输出可能产生重复内容，收益依赖工作负载。
当前不支持关闭 Tiel drafter、DFlash2 block=2／4／16、MoE 的实际 ANE FFN，以及 4B 专用 FFN 缓存实验。Fast top-k 在本轮 greedy 中不执行。
