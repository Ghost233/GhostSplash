## 保留的约束

- 独立开关默认关闭，固定预算和全驻留要求保持原语义。
- 由真实模型格式决定下限、上限、块取整及容量比例，辅助开销单独计费。
- 一个本地控制器统一约束自动专家与自动 PLE，总配额受用户全局与存储上限约束。
- Warning 按缺口缩容，Critical 尝试降到下限，缺失遥测时停止可选增长。
- Normal 或 Warning 满足恢复余量并稳定 30 秒后，本实例每 5 秒最多增加一个真实块。
- 本地必需分配与可选增长分开，保持原等待期限，回收额度不提高 KV／状态上限。
- 保留原映射、数值误差、完整提交状态和生成对照标准，不运行整机压力或性能测试。
- 本轮实模只用 Tiel、单实例、并发 1；真实 PLE 项明确保留未验收。
