# 专家缓存压力控制采用独立开关并保留固定预算语义

按系统内存压力伸缩自动存储采用独立可选开关，默认关闭。
开启后调整 auto 专家预算；自动 PLE 与专家总额的关系见 ADR 0002。
手动指定的专家预算保留固定语义，避免改变已有配置的运行行为和复现条件。
用户接受通过缩小缓存降低推理吞吐量，以优先维持整机响应。

2026-10-27 的范围调整保留这项配置约束。
单实例入口按 [ADR 0005](0005-single-instance-memory-control.md) 改造，验收状态见[使用说明](../moe-memory-control.md)。
