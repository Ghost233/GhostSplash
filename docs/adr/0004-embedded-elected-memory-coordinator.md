# 由 Splash 参与实例选举内存协调者

2026-10-27 用户取消跨实例共享设计，本决策由 [ADR 0005](0005-single-instance-memory-control.md) 取代。
以下保留原决策背景，当前交付不再实施选举、共享配额、心跳或接任。

用户要求多个实例共享内存配额，并自动选举 manager，不单独启动管理进程。
每个参与实例包含相同的协调能力，由唯一获选的实例承担配额协调，其余实例登记需求和实际分配。
这样无需额外维护常驻服务，也能避免各实例同时把整机余量视为自己的可用额度。

共享范围为同一台 Mac、同一系统用户，跨模型和仓库生效；系统基础预留只计一次，多个请求值取最大值。
采用操作系统锁和本地通信。只有取得唯一领导锁才接任，失联但仍持锁时冻结新增长而不强抢。
先保证活跃实例最低需求、优先回收空闲可选缓存，再向活跃实例公平分配额外字节。
配额协调与模型权重存储分开，协调者不直接持有或释放其他实例的模型缓冲。

原协调实现与测试保留为历史，不能作为新单实例路径的验收结果。
任务 #3、#8 和 #10 已退出当前计划，相关运行时依赖需由单实例改造移除。
