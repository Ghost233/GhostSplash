# 压力控制器统一管理自动专家和 PLE 存储总预算

单个运行实例内，系统内存压力控制器决定 auto 专家和 auto PLE 的可用总预算，现有配额优化仅在此预算内调整比例。
这样可避免专家缩容后由 PLE 自动补回内存，也让没有 PLE 的 MoE 使用同一控制边界。
手动 PLE 配额保持固定；内存不足时按已确认的资源等待规则处理。

系统预留余量复用现有 auto 规则，并允许手动指定大小。
2026-10-27 的范围调整保留实例内联合预算，取消跨实例配额分配。
单实例入口按 [ADR 0005](0005-single-instance-memory-control.md) 改造，历史组件结果不代替新路径验收。
