# 单个 Splash 实例独立管理自动存储配额

2026-10-27，用户要求只考虑一个运行中的 Splash 实例，取消跨实例共享内存管理。
本决策取代 ADR 0004 的选举与协调设计，保留 ADR 0001～0003 的开关、实例内预算和回收保护约束。

压力控制器只管理当前实例的自动专家与自动 PLE 缓存，其他进程只影响系统观测。
启动、分配、恢复和状态均使用本地预算，不依赖 socket、领导锁、心跳、任期或共享账本。
原有 30 秒稳定观察和 5 秒单块恢复改为在本实例内生效。

同日用户补充：Warning 是常见运行状态，不要求系统先转为 Normal。
Normal 和 Warning 均按真实余量决定缩容、保持或恢复。
低于基础预留加 1 GiB 时按缺口缩容；达到基础预留加 2 GiB 并稳定 30 秒后允许逐块恢复。
重复 Warning 不重置合格稳定期。Critical、未知压力、低余量或失败使旧许可失效，
分配与块提交前再次检查，保留原硬预算、数值与超时标准。

当前代码已移除旧协调依赖及专用测试，旧全局记录保留，不安排恢复或迁移。
既有组件已接入本地路径；状态、预算、数值与恢复验收记录见[使用说明](../moe-memory-control.md)。
